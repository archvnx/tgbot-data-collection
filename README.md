## Асинхронный Telegram-бот, который собирает в БД пользователей, а также отправленные ими сообщения и фотографии

### Стек:
БД: SQLite
библиотека: aiogram

### Описание работы:
команда /start заносит в БД id тг-аккаунта, присваивает локальный уникальный id, запоминает дату регистрации и выставляет стандартный статус is_banned

по команде /create бот запускает сценарий, по которому ожидает сначала текст, потом принимает до 3-х фото. 
в конце бот высылает пользователю для перепроверки эти данные и запрашивает подтверждение, после подтверждения все заносится в бд.

### Запуск
main.py для запуска
необходимо создать свой config.py и занести туда строчную переменную API_BOT с токеном от бота
