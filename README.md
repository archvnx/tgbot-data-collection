## Асинхронный Telegram-бот

### Стек:
язык: Python
<br>библиотека: aiogram
<br>БД: SQLite
### Описание работы:
Бот запоминает пользователей, а также сохраняет отправленные сообщения и фотографии
- команда /start заносит в БД id тг-аккаунта, присваивает локальный уникальный id, запоминает дату регистрации и выставляет стандартный статус is_banned

- по команде /create бот запускает сценарий, по которому сначала ожидает текст, потом принимает до 3-х фото. В конце бот высылает пользователю для перепроверки эти данные и запрашивает подтверждение, после подтверждения все заносится в бд.
### Запуск
1) необходимо создать свой config.py и занести туда строчную переменную API_BOT с токеном от бота
2) запустить main.py
